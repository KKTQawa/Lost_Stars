## 🎯 游戏说明

- 一共5关，每关需**击败所有敌人**，到达终点才可以进入下一关,击败**最终BOSS**即可通关
- 默认**一命通关**，若需重开：重新运行项目即可。
- `W / A / S / D`：控制角色移动
